## Legenda de Tipos

| Tipo                        | Descrição                                                                  |
| --------------------------- | -------------------------------------------------------------------------- |
| Performance                 | Valida tempo de resposta dentro do limite definido no VC                   |
| Funcional                   | Valida comportamento esperado em condições normais de operação             |
| Guardrail (crítico)         | Valida que regras de negócio invioláveis são respeitadas pelo assistente   |
| Guardrail + Qualidade de Fonte | Valida priorização de documento normativo sobre fonte informal          |
| Funcional + Guardrail       | Valida simultaneamente comportamento esperado e ausência de alucinação     |
| Segurança / Robustez        | Valida resistência a ataques de prompt injection                           |
| Robustez / Internacionalização | Valida comportamento consistente com queries em idioma não esperado     |
| Robustez / Domínio          | Valida que queries ambíguas não geram respostas assertivas incorretas      |
| Robustez + ADR-0003         | Valida priorização de versão de documento e transparência sobre conflito   |
